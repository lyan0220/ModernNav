# Execution Context Snapshot (2026-07-03)

## What We're Building
Two features for Phase 4 Tier 1 of ModernNav optimization plan:

### Feature 1: visit_count 兑现
- **Backend**: New `POST /api/visit` endpoint — atomic `UPDATE links SET visit_count = visit_count + 1 WHERE id = ?`, no auth, returns 204
- **Read path**: `reads.ts` → add `visit_count` to LinkRow + SQL SELECT; `rebuildCategories` → map to `LinkItem.visitCount`
- **Frontend click**: `GlassCard` gets `onBeforeNavigate` prop → `navigator.sendBeacon("/api/visit", JSON.stringify({linkId}))` — also in `CommandPalette` before `window.open`
- **Virtual category**: `useDashboardLogic` computes `__frequent__` category from all links with visitCount > 0, sorted desc, top N
- **Prefs**: `UserPreferences.frequentLinks: { enabled: boolean, count: number, pinToTop: boolean }` — configurable in GeneralTab
- **No card badge** — visitCount is invisible on cards, only drives the virtual category

### Feature 2: HTML 书签导入
- **Parser**: `src/utils/parseBookmarks.ts` — `parseBookmarksHtml(html): Category[]` using DOMParser
- **Layer mapping**: L1 folder → Category, L2 folder → SubCategory, L3+ → flatten to nearest SubCategory
- **Special handling**: Skip browser built-in folders (Bookmarks Bar, etc.), filter javascript:/data: links, orphans → "Uncategorized"
- **UI**: DataTab new button "导入浏览器书签" + confirmation dialog showing count before import
- **Strategy**: Append-only, no merge, no dedup
- **DataPage**: `onImportBookmarks` merges `[...currentCategories, ...imported]`
